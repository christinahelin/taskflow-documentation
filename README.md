# TaskFlow Documentation

TaskFlow is a fictional project management application designed to help teams organize projects, assign tasks, track deadlines, and monitor progress.

This documentation project demonstrates how user-focused documentation can support team members, project managers, and administrators as they use the application.

## Documentation

- [Getting Started with TaskFlow](docs/getting-started.md) — Learn about user roles, sign in to TaskFlow, and navigate the dashboard.
- [View Your Assigned Tasks](docs/assigned-tasks.md) — Learn how to view, filter, and review assigned tasks.
- [Update a Task Status](docs/update-task-status.md) — Learn how to update task progress and document blocked work.

## About This Project

This repository is a technical writing portfolio project created to demonstrate software documentation skills in a GitHub environment.

The documentation demonstrates:

- Task-based procedural writing
- User-focused instructions
- Information organization and navigation
- Markdown authoring
- Git branching and pull request workflows
- Documentation maintenance and version control

TaskFlow is a fictional application created solely for this portfolio project.
