# View Your Assigned Tasks

Use **My Tasks** to view tasks assigned to you, check due dates and priorities, and track the status of your work.

## View Your Tasks

1. From the left navigation menu, select **My Tasks**.
2. Review your assigned tasks in the task list.
3. Select a task to view its details.

The task list displays the following information:

| Column | Description |
| --- | --- |
| Task | Name of the assigned task |
| Project | Project associated with the task |
| Due Date | Date the task is due |
| Priority | Priority assigned to the task |
| Status | Current status of the task |

## Filter Your Tasks

Use the filters above the task list to narrow the tasks displayed.

You can filter tasks by:

- Project
- Status
- Priority
- Due date
