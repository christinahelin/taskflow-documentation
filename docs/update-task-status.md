# Update a Task Status

Update the status of a task to reflect your current progress and keep your team informed.

## Available Task Statuses

TaskFlow includes the following task statuses:

| Status | Description |
|---|---|
| Not Started | Work on the task has not begun |
| In Progress | Work on the task is currently underway |
| Blocked | Work cannot continue until an issue is resolved |
| Complete | Work on the task is finished |

## Update the Status of a Task

1. From the left navigation menu, select **My Tasks**.
2. Select the task you want to update.
3. Locate the **Status** field in the task details.
4. Select the appropriate status from the drop-down menu.
5. Select **Save**.

The updated status appears in your task list and is visible to the project manager.

## Mark a Task as Blocked

If you cannot continue working on a task, change the status to **Blocked** and add a comment explaining what is preventing you from completing the task.

1. Change the task status to **Blocked**.
2. In the **Comments** section, describe the issue preventing you from continuing.
3. Select **Add Comment**.

Providing this information helps the project manager identify and address issues that may affect project deadlines.
